Wij zijn Code for NL

Code for NL is de Nederlandse community van public techies: mensen die samenwerken aan een open, eerlijke en inclusieve digitale overheid en samenleving.

Ons doel is de succesvolle digitale transformatie van de overheid en de samenleving als geheel.

Code for NL is ontstaan uit waag en governing partner van het internationale Code for All netwerk.
